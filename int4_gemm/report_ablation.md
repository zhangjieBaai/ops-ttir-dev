# INT4 GEMM 最终版 TTIR 消融实验

研究第六轮保留的 `r3/group128`；不修改冻结基线、候选或优化别名。每个 shape 的 `final.ttir` 与第六轮 `optimized.ttir` SHA256 相同。固定 H100、官方 Triton3.7.0、30点、FP16/uint8、group128及逐点原配置。主测 GPU0 seed42 7轮，独立进程 GPU1 seed123 5轮，均 rep20ms。两次在各自同卡测量全部版本与共同 baseline，跨卡不直接相除绝对时延。[完整协议](ablation_plan.md)

## 逐项加入的条件收益

每个 shape 先取同轮 `before_us/after_us` 的中位数，再跨30点求几何平均。这些是直接同会话的条件对照；百分比不能相加。首轮组合仍把共享、标量化和unsigned合并，本报告不把其收益拆给未单独复测的首轮成分。

| 对照 | 加速比 |
| --- | ---: |
| 原始基线 → 首轮组合 | 1.0838× |
| 首轮组合 → 窄加载 | 1.9588× |
| 首轮组合 → 去 K mask | 1.0019× |
| 窄加载 → 再去 K mask | 1.0396× |
| 去 K mask → 再窄加载 | 2.0316× |
| 两项均启用 → 组内复用 | 1.1114× |
| 组内复用 → group128 右移 | 1.0309× |

去K mask单独启用的均值仅1.0019×/1.0016×，最差shape为0.8131×/0.8159×（均为M256,N4096,K4096）。在窄加载之后加入则约1.039×。因此不能把K mask删除称为无条件提升；当前收益与其余编译结构有关。

## 从最终版移除改动

数值为缺少改动的版本耗时/最终版耗时。组内复用生成器依赖窄加载结构，最后一行联合移除两项，不能解释为窄加载的纯独立贡献；窄加载的干净对照见上一节2×2。BK128上的组内复用步骤本来就是恒等变换，不把它当作该子集的一项收益。

| 去掉的改动 | 条件加速 |
| --- | ---: |
| group128 右移 | 1.0309× |
| K mask 简化 | 1.0194× |
| BK64 组内复用 | 1.1015× |
| 窄加载和组内复用（联合移除） | 2.3278× |

## 正确性、计时与限制

每次显式pipeline均通过30点源码/TTIR文件入口LLVM/PTX/cubin及输出一致性。各会话30×10×5=1500项版本/分布检查全部通过，先完成完整正确性矩阵才计时。random/extreme_nibble/zero_scale/zero/constant五种分布，对照FP32 ATen，N≤256另对照CPU FP64，候选与baseline逐元素完全一致（torch.equal）、输出canary和输入不变。全部A/A中位数在[0.97,1.03]。

每版每点100ms稳定阶段，随机次序、预分配CUDA graph单fused kernel计时，保留所有样本。未锁时钟、未给置信区间；低于约1%的差异不据此证明可靠提升。只覆盖既定有限shape/分布，不外推其他packing/dtype/GPU，也不代表冷cache或端到端。第六轮正式路径已有[memcheck](multiround/r6/memcheck.log)/[racecheck](multiround/r6/racecheck.log)零错误记录；本轮新增中间消融没有另跑sanitizer。

## 普通 Triton 源码表达能力

共享scale/zero、标量group索引、unsigned索引、窄tl.load后broadcast、删除契约内恒真mask、两次dot共用组参数、以`k0 >> 7`代替除128，都能用公开Triton表达。已有[首轮源码回写实测](source_port/report.md)只覆盖首轮组合，不能当作本最终组合的源码性能对照。本轮没有运行最终组合的源码回写；可表达同一算法不意味着相同机器码或相同性能。

| 改动 | 公开Triton对应写法 | 本轮结论 |
| --- | --- | --- |
| 共享low/high组参数 | 同一scale/zero值被两支引用 | 可表达；首轮已有组合源码实测 |
| group标量化/unsigned | 标量`k0 // group`后广播；`tl.cast(..., tl.uint32)` | 可表达 |
| 窄加载 | `tl.load`读取1×N参数，再broadcast到K维 | 可表达；最终源码性能未测 |
| 去K mask | 在契约保证整除时省去K维mask | 可表达，不能推广到K尾部 |
| BK64组内复用 | 两次顺序`tl.dot`共用组参数 | 可表达，dot顺序须保持 |
| group128右移 | 非负`k0 >> 7` | 可表达，group必须为128 |
