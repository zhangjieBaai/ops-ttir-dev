# Vector add TTIR 优化

来源：官方 Triton 向量加教程。固定上游版本后导出 TTIR，基线的源码编译与 TTIR 编译在 LLVM IR、PTX 和 cubin 阶段一致。

环境：官方Triton3.7.0/H100，FP32连续输入、独立buffer、16-byte对齐，N为16倍数且≤2²⁷。每CTA1024元素、4 warps，16点，9轮20ms。预分配CUDA graph设备时间，不含分配、编译和CPU launch。

**最终平均加速比：算术平均1.009983×，几何平均1.009351×。** 共16个shape，A级证据。

优化方法与性能提升：

1. **输出写入采用.cs缓存策略。** 完整矩阵几何平均1.0094×，N=2²²局部约1.1539×。

   ```diff
   - tl.store(Y + offsets, x + y, mask=offsets < N)
   + tl.store(Y + offsets, x + y, mask=offsets < N, cache_modifier=".cs")
   ```

   流式输出提示让写出数据采用更易淘汰的缓存策略，可能减轻输出对输入或其他数据的缓存挤占。它不减少加法数量或有效输出字节，局部收益也不代表所有N都加速。完整矩阵未达原1.02×门槛，最终采用来自用户接受局部收益；不把其他设备上的约1.206×混入本会话。

36个数值用例和A/A通过。当前TTIR/cubin与已有sanitizer证据相同，因此复用零错误记录，不将其称作本会话重新执行。无冷缓存或API端到端性能结论。
