# Attention dK/dV 第六轮 TTIR 优化

沿用32个冻结shape、4warps/5stages、ABI/grid/workspace和逐位输出合同。parent为r5有效版本，anchor为第二轮有效版本。只修改TTIR，未重新调参或回写源码。

## 本轮新改动

`r6_dv_late`在D128的已验收64-key结构中，把概率FP16转换和dV dot移至dK dot后；第一轮相关D128负结果使用的是128-key原基线，本轮是不同结构上的新组合。

`r6_fission_v_then_k_v2`在同一CTA内将每个64-key块分为dV-only遍历和dK-only遍历。先存dV，再重新计算QK/概率并计算dK。每个accumulator原有masked/unmasked顺序及dot次序不变，无额外全局工作区；无别名合同允许该store顺序。代价是重复QK、概率和部分load。SSA依赖切片删除各pass不需要的运算和循环携带状态。

D64两种候选均为逐字节parent fallback，是完整矩阵控制，不计为新算法收益。初版fission因数字SSA重命名和subtile常量作用域缺陷解析失败，保留v1文件、生成器快照和pilot日志；v2修复后独立验证。

## 验证与复现

官方Triton3.7.0/H100，GPU4独占且正式screen/main/repeat统一锁SM1200MHz；每路初始实际500ms、每次测量前实际100ms等条件预热，计时本体仍为原do_bench_cudagraph。主测7轮、独立seed123复测5轮，rep20为库参数，全部随机顺序/配对样本保留。预分配设备时间不含Python、分配、参考或编译，未主动清cache。

全32点原source/file baseline的LLVM/PTX/cubin gate通过；screen/main/repeat/memcheck/racecheck的检查次数为{'screen': 220, 'main': 176, 'repeat': 176, 'memcheck': 176, 'racecheck': 176}。44输入覆盖32正常输入及四组各3压力输入；N128 normal另外CPU FP64参考。所有输出按int16原始位型与baseline一致、有限性/覆盖及输入不变检查通过。memcheck0 errors，racecheck0 errors/0 warnings。clock_run.json记录finally恢复自动频率成功。
sanitizer覆盖各组冻结的正式候选及baseline/anchor/parent。未选中的D128 fission完成数值与初筛，未额外运行sanitizer；D64同名fission标签只是未改parent。

两个改动分别可用公开Triton表达式顺序和串行循环/多输出分开计算表达；本轮只说明结构对应关系，未做源码JIT性能或机器码一致性实测。
