# Attention 反向 dK/dV 的 TTIR 优化

来源为 Triton v3.7.0 fused-attention 教程中截至 dQ 之前的 dK/dV 计算。输入 FP16，dot 以 FP32 累加。基线冻结每 CTA 负责 128 个 key 的 grid，4 warps、5 stages、1 CTA，候选从 TTIR 文件入口经原生后端编译。[上游与提取记录](upstream/provenance.json)

环境为 H100 80GB，SM 固定 1200 MHz。下表沿用第六轮 32 个 shape 的预分配 CUDA graph kernel 计时，主测 7 轮、独立进程复测 5 轮，rep=20 ms。每个 shape 取同轮原始基线耗时与实际选中版本耗时的配对比值中位数。forward、K 预缩放、delta、编译及分配耗时均在计时范围之外。

## 优化方法与消融

D64 使用首轮已验收的 dV 后移。将概率的 FP16 转换及 dV dot 移到 dK dot 后，保留各 accumulator 的累加次序。首轮 6 点几何平均 1.1241× / 1.1214×；第六轮在固定频率的 16 个 D64 点重新计时，见上表。[首轮消融与负结果](report_round1.md)

D128 的最终实现分三步：每个 CTA 串行处理两个 64-key 输出块；非因果组依据 query 行坐标重算指针，因果组静态展开两个子块；最后在各自结构上后移 dV。缩小子块也增加读取 Q/dO 的次数。两组都保留原有 query 遍历及掩码顺序。第六轮将 dV 和 dK 拆成两个循环的候选因重复计算 QK/概率而额外增加工作，初筛相对上一版只有 0.7290× / 0.6604×（非因果 / 因果，B级）。[第二轮结构实验](round2/report.md) · [第三至五轮负结果](multiround/report.md) · [第六轮对照](multiround/r6/report.md)

### D128 逐项配对消融（本次补测）

在原矩阵全部 16 个 D128 shape 上，分别在 GPU0（7 轮，seed 20）和 GPU1（5 轮，seed 123）独立测量四个阶段。每轮随机交错四个阶段和一路 baseline 副本。两组各 8 个 shape，表内前三行是相邻阶段的条件增量，末行直接对照同轮原始基线。各点先取配对比值中位数，再取组内几何均值。两个进程均预先通过 32 点源码/文件编译一致性检查；消融各版本在计时输入上另做 dK、dV 逐位对照。沿用第六轮 CUDA graph 计时预算与热身协议。

| 改动 | 非因果主测 | 非因果复测 | 因果主测 | 因果复测 |
|---|---:|---:|---:|---:|
| 串行两个 64-key 子块 | 2.7280× | 2.7201× | 2.3686× | 2.3615× |
| 指针重算 / 两次子块静态展开 | 1.0534× | 1.0548× | 1.1101× | 1.1081× |
| 在既有结构上后移 dV | 1.0526× | 1.0506× | 1.0436× | 1.0437× |
| 原始基线至最终实现（同场） | 3.0309× | 3.0144× | 2.7490× | 2.7279× |

单独减小 key 子块贡献了最大增量。其后指针重算给非因果组带来约 5% 增量，展开外层循环给因果组带来约 11% 增量。A/A 各点中位比为主测 0.9964–1.0021、复测 0.9983–1.0005。两卡启动日志均记录成功设置 SM 1200 MHz，结束后均已恢复自动频率；原始 JSON 快照的通用布尔字段未感知外部锁频，实际采样频率见同一文件的 GPU 查询结果。[主测原始样本](ablation/main.json) · [独立复测样本](ablation/repeat.json) · [主测日志](ablation/main.log) · [复测日志](ablation/repeat.log)
