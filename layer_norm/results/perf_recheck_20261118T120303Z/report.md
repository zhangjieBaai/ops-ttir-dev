# 当前 TTIR 性能复测

2026-11-18；隔离 GPU 7，H100 80GB HBM3；独立环境 `/root/venvs/ir-ops-dev/bin/python`，Triton 3.7.0，无 FlagTree/FlagPrism。

输入为 `ir/baseline.ttir` 与 `ir/optimized.ttir`，同一 Triton 原生后端、同一编译/启动选项。运行前 pipeline 核查通过，编译产物与上一轮一致；复用哈希完全匹配且已通过 284 次检查的正确性记录。此次未修改 kernel。

FP16，FP32 累加；M=4096，N=1024..15872 step512，共 30 个 shape。8 warps、1 CTA、3 stages。预分配相同输入输出，CUDA graph 配对计时，每点 7 轮、rep=20ms，随机对内执行顺序；加速比取配对比值的中位数，再跨 shape 汇总。

- 算术平均加速：**1.3145×**（上一轮 1.3142×）。
- 几何平均加速：**1.2927×**（上一轮 1.2925×）。
- 逐 shape 加速范围：**1.1660×–2.4162×**，30/30 个 shape 加速。
