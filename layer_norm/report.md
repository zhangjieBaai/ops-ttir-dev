# LayerNorm TTIR 首轮实验报告

推荐 TTIR：`ir/optimized.ttir`，与 `tile_dispatch_math_v2.ttir` 字节一致。

H100 上 30 个 shape 的加速比：算术平均 **1.314×**，几何平均 **1.293×**；独立进程、更换随机种子的 5 轮复测分别为 **1.316× / 1.294×**。

## 基线与范围

官方 Triton v3.7.0 教程 `_layer_norm_fwd_fused` 前向；从源码导出冻结 baseline.ttir，TTIR 重编译的 cubin 与源码编译一致，Y/Mean/Rstd 逐位一致。官方 Triton 3.7.0 后端，PyTorch 2.12.0+cu130，H100 80GB HBM3 / SM90，隔离 GPU 7。

FP16 输入/输出/W/B，FP32 累加和统计量；8 warps、1 CTA、3 stages。baseline tile=8192，优化版在 TTIR 内按 N 选择逻辑 tile。N/stride 为正的 16 的倍数，指针对齐、列连续、X/Y 同行 stride、不支持别名。未验证其他 dtype、非对齐 N 或特殊非有限输入。

## 采用的 TTIR 修改

- 对 N≤1024/2048/4096/8192 分别添加单 tile 路径，使用对应 tensor 宽度。
- 对 8192<N≤16384 展开两次 masked tile；N>16384 保留通用三遍循环。
- 保留 mean→中心化 variance→输出的算法；展开使 mean/variance 的输入加载可以被后端合并，输出阶段在统计量 store 后仍保留一次 X 加载，未宣称所有输入只加载一次。
- 共用 1/N，再乘法计算 mean/variance；`math.sqrt + arith.divf` 改为 `math.rsqrt`。

所有候选均直接编辑 TTIR；没有手工修改 TTGIR/LLVM/PTX/cubin，编译选项保持相同。浮点计算允许容差内舍入变化，未要求优化版与 baseline 逐位等价。

## 正确性与资源

6 个合法版本各 142 个用例、共 852 次检查通过。包含原 31 个 shape、小 M、constant/offset/zero_mean、大尺寸通用路径、分支边界、padding=16 和 eps=1e-6/1e-3。Y 对 native ATen 最大绝对误差 <1e-2；Mean/Rstd 对 FP64 参考分别按 (rtol,atol)=(2e-5,1e-5)/(2e-4,1e-5) 验证；每版运行前重置输出 sentinel 并检查行尾 padding 未写坏。

baseline 与最终版各 17 个边界/padding 用例经过 memcheck 和 racecheck，工具均报告 0 errors。最终版资源为 80 registers/thread、n_spills=2、shared=32 B；baseline 为 60 registers/thread、n_spills=0、shared=32 B。优化版有局部内存 spill，当前收益不代表寄存器占用得到改善。

## 消融、负结果与证据

| 候选 | 6 点筛选几何平均 | 寄存器/thread | n_spills |
|---|---:|---:|---:|
| canonical | 1.000× | 60 | 0 |
| arithmetic | 1.009× | 60 | 0 |
| single_tile | 1.196× | 64 | 0 |
| tile_dispatch_v2 | 1.358× | 80 | 2 |
| tile_dispatch_math_v2 | 1.362× | 80 | 2 |

canonical 仅去除调试位置，其 ELF .text 哈希与 baseline 相同，计时约 1.000×。初始 tile_dispatch / tile_dispatch_math 因零常量尺寸不匹配在 C0 失败，原文件和失败说明保留，未执行或计入正确性结果。v2 使用分支局部零常量修正。结构修改与算术修改有独立候选，但未对每个分支宽度或单项算术做完整消融，不能拆分总收益。

完整结果：`accuracy_full.json`、`screening.json`、`full_benchmark.json`、`independent_repeat.json`、`memcheck.log`、`racecheck.log`、`selection.json`、`artifact_manifest.json` 均在 `results/`。复现命令见 README。

## 下一轮方向

优先研究双 tile 路径的值存活期和 spill，拆分输入复用与动态循环消除的收益；增加受控冷缓存和应用调用测量后再评估部署收益。扩展 BF16/FP32 或非 16 对齐尺寸时，应另行从教程导出匹配签名/属性的 baseline 并验证，不复用本轮精度结论。
