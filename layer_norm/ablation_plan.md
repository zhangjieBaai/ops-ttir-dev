# 前向 LayerNorm 消融

固定官方 Triton 3.7.0、H100、8 warps/3 stages/1CTA、原baseline、FP16数据和原数值阈值，M4096、N1024..15872步长512。逐项累加：baseline → 倒数复用/rsqrt → 2048动态分组 → 范围静态展开 → mean阶段.ca → 输出.cs → 小N混合1024分组。再从最终版逐项移除.ca、.cs、小N混合和静态范围展开。因结构相依，动态分组/静态展开/小N混合无法假装成完全独立开关，报告条件效应，不能相加成总收益。

所有候选142例正确性及最终相关120边界检查先于性能；同一GPU串行，完整30点主测5轮rep10ms，独立seed123复测3轮rep10ms，全部保留配对baseline和A/A。稳定阶段每版100ms。不调整现有optimized别名，不重新择优。另写公开Triton API的最终算法示例，导出TTIR、核查源码/文件入口下游一致，并纳入相同正确性和性能测量；不能把算法可表达等同于机器码或性能相同。
