# MM TTIR 优化与消融结果汇总

全31点TMA扩展已完成，最新数据、配置组选择与资格限制见 [全31点TMA扩展报告](host_allshape_v1/report.md)。下文保留此前分组实验记录。

整理日期：2026-11-20。由已有原始 JSON 配对样本复算，核对当前选择与 TTIR 哈希；本次未运行 GPU、未新增性能实验。所有时间单位为 **µs**。

## 1. 结论与比较口径

当前旧接口仅采用 `r1_unsigned`，作用于 384³、512³、640³，主测/独立复测几何加速比 **1.0510× / 1.0507×**（A级，仅这三个点）。其余28点回退 baseline。大尺寸部分 A/A 控制无效，尚无全31点可靠整体加速结论。

host descriptor 路线在768³至1408³六点的设备时间为 **1.1247× / 1.1171×**；它改变了参数接口，且仍有37条 racecheck warning、`sync_qualified=false`。完整六点和独立复测支持该条件下的设备性能观测，不能授予同步资格，也不能外推成旧接口调用加速。

- 加速比 = 同轮 baseline 耗时 / candidate 耗时；>1 更快，<1 回退。逐点取配对比值中位数，跨 shape 等权取几何均值。

- 时间列各自取轮次中位数，因此两列时间直接相除可能不等于配对加速比。

- 除另有说明，为 H100/SM90、FP16 输入输出、官方 Triton 3.7.0 原生 TTIR 编译、预分配输出的 CUDA graph 设备时间；不含编译、加载、分配和 Python 准备。未锁频或主动清缓存。

- 首轮主测7轮、seed123独立进程复测5轮；初筛3轮。下述各路线主测/复测均 rep=20ms。不同路线的耗时不能跨进程直接相除来做消融。

- 证据等级：A=对应分组完整矩阵及独立复测且计时控制有效；B=初筛、未独立复测或带无效性限制的观测；C=静态编译/哈希/资源事实；D=尚无对应测量。性能等级与数值、内存、同步检查分别判断。

## 4. 首轮优化方法与消融

### 4.1 方法定义（C级源码/产物事实）

| 候选 | 改动 | 结论 |
|---|---|---|
| r1_canonical | 仅删除调试 loc；六组可执行 section 与 baseline 相同 | A/A控制，不算优化 |
| r1_unsigned | 将已证明非负的索引 divsi/remsi 改为 divui/remui；保留浮点 dot/累加顺序 | 仅F2采用 |
| r1_wrap_select | A行/B列越界索引改选合法0，替代取模 | 未采用 |
| r1_k_aligned | K整除BK时分支到无K尾mask循环，否则原循环 | 未采用；F4资源失败 |
| r1_cache_cg | 两个输入load加 cg 缓存属性 | 六组可执行section与baseline相同，无已建立收益 |
| r1_unroll2 | K循环加 unroll factor=2 提示 | 六组可执行section与baseline相同，无已建立收益 |
| r1_wrap16 | 越界索引改为 index & 15，并增加contiguity=16提示 | 未采用 |
| r1_wrap16_unsigned | wrap16 与非负索引无符号除余组合 | 未采用 |

unsigned 在F2是5处 div、4处 rem 的改写；baseline/candidate 均72 registers、0 spill、81920 bytes shared。PTX显示符号修正变化，但未把每项机器指令变化单独消融。正尺寸、正16倍数及无整数溢出的实验输入约束是合法性前提。
